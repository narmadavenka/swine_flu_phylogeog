Repository overview README for manuscript by Venkateswaran et al. (2026) "Swine production networks structure the long-term spatial evolution and connectivity of H3 Influenza A viruses in the United States"

/sequences
	- contains all sequence files, processing code files, and related metadata files

/trees
	- contains all maximum clade credibility (mcc) trees as well as sampled posterior distribution trees

/phylogeography
	- contains the main code and outputs for the phylogeographic GLM

/figures
	- contains the code and figure outputs generated for the manuscript
